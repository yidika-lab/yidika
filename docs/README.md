# Yidika documentation

*Yidika* means "to design, to arrange, to put back in order" in Kikongo. The language takes that literally: you write a program once, and `yidi` either runs it straight away in an interpreter or arranges it into a native binary through LLVM. Both engines must print the same thing for the same program, and every example in these pages is run through both by the test suite.
